# Dex 0.2.0 ekran görüntüleri

Uydurma demo verisiyle (takım "Orbit", ödeme sayfası işi) üretilir; kişisel veri içermez. Yeniden üretmek için: `pnpm screenshots` (betik: `scripts/screenshots/`, tam e2e paketine girmez).

- `01-workspace.webp` — Ana çalışma alanı: Kart (A · Doku), lider ve worker panelleri; üç worker çalışıyor, sekmelerde iş ilerlemesi.
- `02-kart.webp` — Kart yakın plan: Core symbiote, Echo asistanı, worker'lara giden canlı damarlar, çalışan worker'ın etiketinde lazer.
- `03-tasks-board.webp` — Görevler panosu: Yapılacak / Sürüyor / Bitti, süren işlerde ilerleme yüzdesi ve adım.
- `04-usage-strip.webp` — Kullanım şeridi ve Claude halkasının hover kartı (5 saatlik ve haftalık kota).
- `05-settings-providers.webp` — Ayarlar → Sağlayıcılar.
- `06-settings-chain.webp` — Ayarlar → Kota zinciri.
- `07-team-note.webp` — Takım notu: lider sistem istemine ve her mesaja ekler.
- `08-dex-prompts.webp` — Dex istemleri overlay'i: Dex'in ajanlara verdiği istem parçaları.
- `09-chat.webp` — Sohbet görünümü: liderin oturumu, araç kartları ve devretmeler.
